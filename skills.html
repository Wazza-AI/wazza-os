    Skills, learning and personas

    A skill is written know-how an agent loads before it works: how to use GIMP, how to rig a character in Blender, how to write release notes. Wazza OS ships hundreds of them, finds the right ones for each task, and keeps improving them from what happens in your Chats.

    WhatText files of procedures, checks and lessons that agents read
    WhyAgents do app work right the first time, and do not repeat yesterday's mistakes
    WhoEveryone (learning is on by default); power users who tune or write skills
    Where to lookSettings › Skills & learning

    Where skills come from#

    KindWhat it isWhere you see it
    Basic Chat skillsShipped with Wazza OS; every Chat may load them (for example GitHub, Google Workspace, Word documents, architecture diagrams, arXiv papers, Airtable, Apple Notes)Settings › Skills & learning › Skills
    App skillsOne per app: how its agent uses that app (its tools, its menus, its pitfalls)The app's Edit app… (right-click it in Apps)
    The skill library310 specialist skills in 41 domains: 3D, film, video editing, motion, audio, design, game design and game engines, CAD and simulation, writing, office documents, spreadsheets, presentations, software (front end, back end, mobile, testing, security, DevOps, cloud), data and machine learning, growth…Agents search it when a task needs it; personas group them
    Learned skills and lessonsWhat Wazza OS learned from your Chats: new skills, and lessons added to existing ones Learned changes

    You never have to pick skills: when a task needs an app, a tool or a domain the agent has no skill for in its context, it searches all of them first (best matches, with what each costs in context), reads the ones that fit, and follows them.

    How Wazza OS learns#

    At set moments, Wazza OS reviews a Chat's recent turns and keeps one small lesson or skill, with the evidence from the turns (what worked, what failed and its fix), never from the same turns twice. Every agent finds it afterwards, whatever its harness.

    • When: by default every 10 turns, every 30 minutes of agent work, after a Chat has been idle 10 minutes, when a Chat ends, and when it is compacted (How often).
    • With which model: each Chat's own, if it is at least Standard; or the learning model you set (Learning). The tokens it uses are counted in Spent today.
    • Where it applies: to one app (found only from that app's tabs), to everything (General), or to one project.
    • Kept where: on this computer, or also with your account (the default This computer and your account).
    • Per Chat: Learning in this chat off leaves a Chat out; Learn from this chat now reviews it at once (the Chat's model window › Chat settings).

    Wazza OS also learns from how you use apps: the app journal notes the menus, clicks and keys you use in the VM's apps (never a password) and turns them into how-to lessons. It is yours only: pause it or delete its notes in App journal.

    Review and undo what was learned#

    1. Open Settings › Skills & learning › Learned changes.

    2. Each change says what it is (a lesson, a new skill, a removal, a move), where it applies, and which Chat it came from (Open its Chat). Open its details for the evidence and the exact change.

    3. Undo takes it back (a lesson's line goes; a learned skill goes or gets its earlier text back; a removed skill returns). Move to General (or to an app) changes where it applies.

    An app's own lessons also show in its Edit app… under Lessons noted by Chats, with the same Undo.

    Edit or add a skill#

    • A basic skill: Settings › Skills & learning › Skills › Edit on its card. A shipped skill opens as your own copy, which replaces it on this computer.
    • An app's skill: right-click the app in Apps › Edit app… › its skill files (Edit an app's skill). Revert to shipped brings the original back.
    • A new skill: the easiest way is to ask a Chat: "write a skill for our release-notes style, from this conversation", or turn on learning and let it come. For your own app, the skill is a field of its recipe (Add your own apps).

    Personas#

    A persona is an agent role: a description of how it works and a group of skills it loads, for one kind of task. It learns from its own Chats: procedures and tool sequences that worked, pitfalls and their fixes, worked examples.

    • Starter personas: 3D artist (Blender), video editor, image and vector designer, film director, sound designer, motion designer, writer, game designer. They are yours to change.
    • Use one: in a Chat's model window › Chat settings › Persona; or ask a Chat to start an agent "as the film director".
    • Make one: Settings › Skills & learning › Personas › New persona: a name (its role), a description, when to use it, its skills (every field).

    From the command line#

    $ wazza --gui invoke modules_call packages skill_learned '{"action":"list"}'
$ wazza --gui invoke modules_call packages persona '{"action":"list"}'
