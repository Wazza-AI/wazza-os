    Install, update, remove

    Wazza OS installs with one command on any recent Linux, or as a package of your distribution. Start it from your app menu, and it sets up the rest (its VM, its apps, its agents) on its first start.

    What your computer needs#

    NeedWhy
    Linux on a 64-bit Intel or AMD processor (x86-64), with glibc 2.39 or newer (Ubuntu 24.04, Debian 13, Fedora 40 and later, a current openSUSE Tumbleweed or Arch)Wazza OS is built for it.
    Hardware virtualization (Intel VT-x or AMD-V) turned on, so /dev/kvm existsThe VM runs only with KVM. Most computers have it; on some it must be turned on in the firmware settings (UEFI/BIOS).
    A desktop session with systemd (GNOME, KDE, Xfce, Hyprland, Sway…), and XWayland on Wayland desktops Wazza OS's window and the VM's panes are X11 windows. On a server with no desktop, see On a server.
    Memory: 8 GB works (the computer of this manual's screenshots had 8 GB); 16 GB or more is comfortable for 3D apps and several agents at onceThe VM takes memory as its apps need it and gives it back; Wazza OS always keeps 2 GB and 10 % of your memory for your computer itself (Memory, CPU and disk).
    Disk: about 8 GB for Wazza OS itself, plus room for the VM's disk (it grows as you use it, by default up to half of your free space)The package holds the VM's system image.
    A graphics card with its driver (Intel, AMD, or NVIDIA 495 or newer)Apps in the VM draw on it. Without one the VM still works, with slower software graphics.
    An Internet connectionFor agents' models, installing apps in the VM, updates.

    After installing, wazza --check says exactly what your computer has and what is missing (What is checked).

    Install with one command#

    Paste this in a terminal, on the Linux computer where Wazza OS will live. It asks for your password once, for sudo.

    $ curl -fsSL https://os.wazza.ai/install.sh | sh

    To test first, without installing anything:

    $ curl -fsSL https://os.wazza.ai/install.sh | sh -s -- --check
    It…How
    finds your package typeDebian, Ubuntu and their family get the .deb. Fedora and openSUSE get the .rpm. Arch and its family get the Arch package. Any other distribution gets the tarball.
    verifies the releaseNothing installs unless the release manifest carries Wazza's Ed25519 signature and the package matches its signed SHA-256 and size.
    resumes if cutThe package is large (about 7 GB). If the download stops, run the command again: it continues where it stopped.

    It needs free disk for the package plus about 1 GB, and checks before it starts. It downloads into /var/tmp/wazza-install and leaves the package there (delete it to free the space); to use another folder, put WAZZA_INSTALL_DIR=/some/big/folder before sh. To choose the package type yourself, add it after --: sh -s -- tar (or deb, rpm, arch). When it is done, start Wazza OS from your applications menu.

    Or download a package yourself#

    The packages are on Wazza's release server, os-downloads.wazza.ai (its older name, downloads.tadaah.ai, serves the same files, and is the address Wazza OS's own updater uses). Each version has four packages of the same build, one per family of Linux:

    Each file is about 7 GB: it carries the VM's whole system, so the first start needs no further big download. For a newer version: https://os-downloads.wazza.ai/latest names the current version and the Debian package's address and SHA-256 (its files[0].url, relative to https://os-downloads.wazza.ai); the other three are in the same folder, /download/<version>/. In a terminal:

    $ curl -s https://os-downloads.wazza.ai/latest
$ curl -LO https://os-downloads.wazza.ai/download/0.2.0-git.z1793671965.44c5d0ea07c1/wazza-20261103T021245Z-11af2d7099e51d8e.deb
$ sha256sum wazza-20261103T021245Z-11af2d7099e51d8e.deb

    The SHA-256 printed must be the one in the table (or in /latest); if it differs, the download is damaged: download it again.

    You download a package only once. After the first install, Wazza OS updates itself from the Update page: it checks for a new signed version every hour, and installing it is two clicks and your administrator password.

    Install a downloaded package#

    Ubuntu and Debian#

    $ sudo apt install ./wazza-*.deb

    Write the ./ in front: it tells apt to install that file, and apt installs what it needs with it (bubblewrap, ffmpeg, Openbox, Xvfb and the other dependencies).

    Fedora#

    $ sudo dnf install ./wazza-*.rpm

    openSUSE#

    $ sudo zypper install ./wazza-*.rpm

    Arch and Arch-based systems#

    $ sudo pacman -U ./wazza-*.pkg.tar.zst

    Any other Linux (tarball)#

    $ tar --zstd -xf wazza-*.tar.zst
$ cd wazza-os-*/
$ ./install.sh --check
$ sudo ./install.sh

    ./install.sh --check only lists what your system is missing (the commands and libraries Wazza OS needs: systemd, util-linux, Python 3, Xvfb, xauth, Openbox, D-Bus, FFmpeg, bubblewrap, slirp4netns, iproute2, OpenSSL, Git). Install those with your package manager, then sudo ./install.sh puts the files where the packages put them. It refuses while something is missing (--force installs anyway).

    Start Wazza OS#

    Open Wazza OS from your app menu (Activities, the application launcher, or the start menu of your desktop). Or, in a terminal of your desktop session, run one of these (they are the same program):

    $ wazzaos

    wazza-os and wazza work too. Only one Wazza OS runs per user: starting it again while it runs goes to the one already running. The very first start shows six setup steps: The first start.

    Update Wazza OS#

    Three ways, all keep your VMs, Chats, sign-ins and settings:

    • From Wazza OS: Home › Update shows a new version as soon as it is out (it checks every hour); click Download Update, then Install Now (The Update page).
    • With your package manager: download the new package and install it exactly as above, over the installed one (sudo apt install ./new.deb, sudo dnf install ./new.rpm, sudo pacman -U ./new.pkg.tar.zst, or the new tarball's sudo ./install.sh). Then quit and start Wazza OS.
    • With the install command: run it again (Install with one command): it installs the newest version over yours. Then quit and start Wazza OS.
    Never uninstall to update

    Removing the package deletes your Wazza OS data (below). To update, or to go back to an older version, install the other package over the one you have.

    Going back to an older version is a downgrade: Debian and Ubuntu do it with sudo apt install --allow-downgrades ./older.deb; Fedora with sudo dnf downgrade ./older.rpm; Arch with sudo pacman -U ./older.pkg.tar.zst.

    Remove Wazza OS#

    Removing Wazza OS removes your Wazza OS data too

    Every package's removal stops Wazza OS and its VMs, then deletes Wazza OS's data on this computer: the VMs' disks (and every file you made inside them), Chats, sign-ins and keys, settings, caches. Your own files outside Wazza OS (Documents, Downloads, Desktop…) stay, including Downloads/From the VM and VM backups. Back up a VM you want to keep first (Virtual machines › Backups).

    SystemCommand
    Ubuntu, Debiansudo apt remove wazza-os
    Fedorasudo dnf remove wazza-os
    openSUSEsudo zypper remove wazza-os
    Archsudo pacman -R wazza-os
    Tarballsudo ./uninstall.sh (in the unpacked folder)
    Any of themsudo wazzaos --uninstall: removes Wazza OS with the system that installed it (apt, dnf, zypper, pacman or the tarball's uninstaller), naming each folder it deletes with its size

    To erase Wazza OS's data but keep it installed (a fresh start), use Settings › This computer › Remove all data instead.
